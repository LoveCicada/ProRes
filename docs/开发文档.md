# 开发文档

当前播放器的模块划分、一次打开并播放的时序，以及主要类的关系。实现细节见 [development.md](development.md)。

## 设计架构

界面线程拥有窗口、定时器和声卡。解码使用 `std::thread`，不使用 `QThread`。软解和 Vulkan 回读把 BGRA 放进队列；零拷贝由 `VulkanCopy` 写成共享纹理，像素不回到 CPU。`VideoWidget` 用同一块显卡的 DX11 交换链画画面。`MediaProbe` 只在点击「文件信息」时加载 `MediaInfo.dll`。

## 运行时序

下面是一次打开并持续播放。探测只保留成功的路径，默认优先零拷贝，其次回读，最后软解。音频时钟超过约 150 毫秒不前进时，出帧改用经过的时间。窗口缩放时，`VideoWidget` 用上一帧重画新的交换链。

```mermaid
sequenceDiagram
    participant MainWindow
    participant Player
    participant DecodeThread
    participant FFmpeg
    participant VulkanCopy
    participant VideoWidget
    participant Audio as QAudioOutput

    MainWindow->>Player: open(path)
    Player->>DecodeThread: 启动 decodeLoop
    DecodeThread->>DecodeThread: 按显卡 LUID 查找 Vulkan 设备
    DecodeThread->>FFmpeg: 探测软解、回读、零拷贝
    FFmpeg-->>MainWindow: decodeOptionsChanged 与 statusChanged

    loop 读包直到停止或文件结束
        DecodeThread->>FFmpeg: av_read_frame 并解码
        alt 零拷贝
            DecodeThread->>VulkanCopy: copy(frame)
            VulkanCopy-->>DecodeThread: 共享纹理句柄
        else 软解或回读
            DecodeThread->>DecodeThread: 转成 BGRA
        end
        DecodeThread->>Player: 视频帧入队，PCM 入队
    end

    loop 每 15 毫秒
        MainWindow->>Player: takeFrameForClock
        Player->>Audio: 写入 PCM
        Player-->>MainWindow: 到期的 VideoFrame
        MainWindow->>VideoWidget: present(frame)
        VideoWidget->>VideoWidget: 画到 DX11 交换链
    end
```
